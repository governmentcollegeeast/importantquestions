What is Cryptography? Explain Public and Private Key Cryptography in Detail
Government College Ludhiana East • E-Commerce — BBA Semester II Prepared by: Jeevansh Manocha

Introduction

With the rapid growth of E-Commerce and digital communication systems, the security of electronic information has become extremely important. Online business transactions involve sensitive information such as customer data, passwords, financial records, and payment details. If this information is not protected properly, it can be accessed or misused by unauthorized persons.

To ensure confidentiality, integrity, and security of electronic information, businesses use cryptography techniques. Cryptography plays a vital role in protecting online communication and securing E-Commerce transactions against cyber threats and unauthorized access.

Meaning of Cryptography

Cryptography refers to the process of converting readable information into an unreadable form to protect it from unauthorized access. The information can only be accessed or understood by authorized users using special keys or decryption methods.

Definition: Cryptography is the science and technique of securing information by converting data into coded form so that only authorized users can access and understand it.

The original readable information is called Plain Text, while the coded unreadable information is called Cipher Text.

Objectives of Cryptography

  • Confidentiality: Protecting information from unauthorized access.
  • Integrity: Ensuring that data is not altered during transmission.
  • Authentication: Verifying the identity of users.
  • Non-Repudiation: Preventing denial of communication or transactions.
  • Security of Online Transactions: Protecting electronic business activities and payments.

Types of Cryptography

Cryptography is mainly divided into two major types:

  • Private Key Cryptography (Symmetric Cryptography)
  • Public Key Cryptography (Asymmetric Cryptography)

1. Private Key Cryptography

Private Key Cryptography is also known as Symmetric Key Cryptography. In this method, the same key is used for both encryption and decryption of information.

In private key cryptography, both the sender and receiver use a common secret key to encrypt and decrypt the message.

Working of Private Key Cryptography

Plain Text Message
↓
Encryption Using Secret Key
↓
Cipher Text
↓
Decryption Using Same Secret Key
↓
Original Plain Text

Both the sender and receiver must know and protect the secret key used in communication.

Advantages of Private Key Cryptography

  • Fast encryption and decryption process
  • Efficient for large amounts of data
  • Simple implementation
  • Less computational complexity

Limitations of Private Key Cryptography

  • Difficulty in securely sharing the secret key
  • Risk of key theft or unauthorized access
  • Less secure for large communication networks
  • Key management becomes difficult with many users

2. Public Key Cryptography

Public Key Cryptography is also known as Asymmetric Key Cryptography. In this method, two different keys are used:

  • Public Key: Used for encryption and available publicly.
  • Private Key: Used for decryption and kept secret by the owner.

In public key cryptography, information encrypted with the public key can only be decrypted using the corresponding private key.

Working of Public Key Cryptography

Plain Text Message
↓
Encryption Using Public Key
↓
Cipher Text
↓
Decryption Using Private Key
↓
Original Plain Text

The public key can be shared openly, while the private key remains confidential and secure.

Advantages of Public Key Cryptography

  • Higher level of security
  • No need to share private keys
  • Supports digital signatures and authentication
  • Suitable for internet and E-Commerce security
  • Improves confidentiality and authentication

Limitations of Public Key Cryptography

  • Slower compared to private key cryptography
  • Requires more computational power
  • Complex implementation process
  • Higher processing cost

Difference Between Public Key and Private Key Cryptography

Basis Private Key Cryptography Public Key Cryptography
Number of Keys Single key used Two different keys used
Encryption & Decryption Same key used Different keys used
Security Level Less secure More secure
Speed Faster Slower
Key Distribution Difficult to share securely Public key can be shared openly
Usage Used for bulk data encryption Used for authentication and secure communication

Role of Cryptography in E-Commerce

  • Protects online payment transactions
  • Secures customer information
  • Prevents unauthorized access
  • Supports digital signatures
  • Ensures secure communication between users
  • Protects business data from cyber attacks

Applications of Cryptography

  • Online banking systems
  • Digital payment systems
  • E-Commerce websites
  • Email security systems
  • Digital signatures and certificates
  • Secure communication networks

Conclusion

Cryptography is an essential security technique used to protect electronic information and online business transactions from unauthorized access and cyber threats. It ensures confidentiality, integrity, authentication, and security in digital communication systems.

Private key cryptography uses a single secret key for encryption and decryption, while public key cryptography uses two separate keys for secure communication. Both methods play an important role in securing E-Commerce systems, online banking, and digital transactions. As online business activities continue to grow, cryptography will remain one of the most important technologies for maintaining trust and security in the digital world.
